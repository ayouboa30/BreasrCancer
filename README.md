# Breast Cancer CNN Study

A personal TensorFlow/Keras project for learning the fundamentals of convolutional neural networks on a breast-cancer imaging task.

## Objective

The notebook explores the complete workflow of a small image-classification project: data preparation, CNN construction, training, evaluation and interpretation of model behavior.


## Limitations

This is an educational project. It is not a clinically validated model, and its outputs must not be used for diagnosis or medical decision-making.
